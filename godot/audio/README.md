# Audio

Drop sound files here and the game uses them in place of its built-in stand-in sounds.
The file name decides which sound it replaces. `.ogg`, `.wav` and `.mp3` all work.

| File name | When it plays |
|---|---|
| `clap` | the player claps (also the Mimic's fake clap) |
| `whisper` | the player whispers |
| `step_0` `step_1` `step_2` `step_3` | footsteps on stone, metal, water, moss |
| `pebble` / `toss` | a pebble lands / is thrown |
| `chime` / `door` | the bronze chime rings / the sealed door opens |
| `hurt` / `kill` | a creature is hurt / destroyed |
| `death` / `descend` | the player dies / reaches the way down |
| `note` / `secret` / `achievement` | story note, secret or upgrade found, achievement |
| `growl` | a Listener hears you |
| `shriek` | a Drifter screams |
| `sleeper_wake` / `sleeper_breathe` | a Sleeper wakes / breathes in its sleep |
| `heartbeat` | danger is close |
| `compass` | Echo Crystal ping toward the exit |
| `ambient_0` … `ambient_3` | random background sounds on stone, metal, water, moss levels |
| `hum` (looping) | the hum that leads to the way down |
| `drone_0` … `drone_3` (looping) | background drone per floor type |
